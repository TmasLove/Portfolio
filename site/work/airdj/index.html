What it is

Live audio broadcasting for mobile and traveling DJs. Plug in, tap Go live, and get a six-character room code and a QR code that anyone nearby can point a camera at. Listeners hear the set in their browser: no app, no account, nothing to download. It is built for the places a set happens without a PA: a plane, a train, a hostel lobby, a back room.

The server only introduces people. Once two browsers have found each other, the audio goes straight from the DJ's device to the listener's, which keeps the delay to about a second. Nothing is recorded, stored or uploaded.

In the app

What it does

  • Go live from any input. Pick the mixer, interface or mic, name the set, and share the link, the QR, or AirDrop from the share sheet. A level meter shows whether there is actually signal.
  • Nearby sets. People on the same Wi-Fi see live sets without needing a code. A DJ can switch that off and stay link-only.
  • Artwork for every set. Each set gets cover art drawn from its room code, so the list, the player and the share card all look like the same set, with nothing uploaded.
  • Reactions and track IDs. Listeners send reactions that ripple up the DJ's screen, and ask for track names. Requests for the same track in different words are merged into one with the votes added up.
  • A recap card. When the set ends, everyone gets a card with time on air, peak listeners and the most-requested track, ready for Stories or TikTok.
  • Built for bad connections. Sound quality adjusts for each listener's connection, and if the DJ drops out in a tunnel, the room is held for 60 seconds and everyone reconnects on their own.

Honest limits

The DJ's device sends a separate stream to each listener, so a room tops out at about 30 people. Some plane and guest Wi-Fi blocks devices from talking to each other; the set shows up but will not play there. On iPhone, listeners tap once to start the audio, because browsers do not let sound start on its own.
