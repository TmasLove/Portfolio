What it is

A mod menu for Cyberpunk 2077, built on Cyber Engine Tweaks for game 2.5. It started with one stuck quest: Letter of the Law would not register that I had gathered what it needed. The usual fix is a console command from a community list, and four of the ids on those lists turned out to be wrong, including one that reads perfectly but belongs to a different quest in a different district.

A wrong id does not throw an error. It does nothing, quietly, so you cannot tell "wrong code" from "code worked, quest still broken". Daemon is built so that never happens.

In game, on the Quest Fixes tab: the cyberpsycho checklist, and the header counting how many ids this install verified.

Nothing fires blind

Every item id is checked against the game's own database when the mod loads. Anything your install does not recognise is greyed out and labelled instead of fired into nothing. Functions cannot be checked that way, so they are probed against the game first, and where neither is possible the menu says it could not verify rather than implying success.

What it does

  • Quest fixes that read the old value before writing, so every change can be reversed from the Undo tab, plus a checklist of all 17 cyberpsycho sightings with their districts.
  • Shards: the conversation shards that fail to spawn on a body, the usual reason a sighting will not complete.
  • Inventory and world: eddies, points, ammo, crafting components, time, weather, and teleports with saved waypoints.
  • Browse: reads every clothing, weapon and vehicle record out of your own running game (about 2,000, 1,800 and 1,400 on a 2.5 install), with search, readable names and a filter for what V can actually obtain.
  • Six palettes, and the whole window is derived from two colours.

What it deliberately will not do

Force-complete a quest, rewrite story facts, or teleport you somewhere you cannot leave. Each of those can break a run in a way an undo cannot reverse, so they are left out on purpose. The line is "can it break a run", not "does it help the player".
